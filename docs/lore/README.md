## Правила ведения
1. Новые идеи помечать как «согласовано», «рабочая сцена», «открыто» или «техническое». Не превращать гипотезы в факты без решения автора.
2. Сохранять различие между событиями мира, личной памятью Миты и сведениями из логов или рассказов.
3. После согласования переносить нужные фрагменты в `extra/Prompts/Common/CharacterSeeds`, `InitialMemories` и, при необходимости, `Default/Lite`.
4. Изменения относительных дат и ранжирования RAG вести отдельно от лорных правок.
5. Не удалять исторические документы при реструктуризации.

## Где выполняется лор
- `extra/Prompts/Common/CharacterSeeds/*.script` — личные стартовые воспоминания.
- `extra/Prompts/Common/InitialMemories/*.script` — RAG-справка и факты мира.
- `extra/Prompts/Common/world_knowledge.script` — подключение общих знаний.
- `extra/Prompts/<персонаж>/Default|Lite` — правила поведения персонажей.

Текущая документация находится в репозитории `NeuroMita/NeuroMitaPython`, ветка `releases`; исполняемые изменения PR #177 — в `Atm4x/NeuroMita`.
